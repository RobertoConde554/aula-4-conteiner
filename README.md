# Aula 4 — Docker e Computação em Nuvem

Nesta aula foi utilizado o **Docker** no Ubuntu para criar e executar containers.

* Verificação da instalação com `docker --version`.
* Teste do Docker usando o container `hello-world`.
* Criação de um container **Nginx** com `nginx:alpine`.
* Utilização da porta `8080` para acessar o servidor.
* Teste de acesso utilizando `curl localhost:8080`.
* Alteração da página inicial do Nginx dentro do container.
* Monitoramento do container com `docker stats`.
* Parada e remoção do container utilizando `docker stop` e `docker rm`.

A atividade mostrou, na prática, como **criar, executar, acessar, modificar, monitorar e remover containers Docker**.
